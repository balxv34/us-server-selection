## 先分清：你需要的到底是哪种美国服务器

判断顺序是先定线路，再定配置，最后才比价格。线路决定国内用户的访问体验，配置决定业务上限，价格只有在前两项定了之后才有比较意义。

- 中文用户访问为主（外贸站、面向国内用户的应用）：认准 CN2 GIA、联通 9929 这类大陆优化线路。洛杉矶三网直连的正常延迟在 130-160ms 左右——这是华纳云在产品页公开标注的数字，可以当作验收基准。机器到手 ping 出 200ms 开外、晚高峰丢包，基本就是普通国际线路。
- 用户在欧美：国际 BGP 大带宽就够，没必要为大陆优化线路多花钱。
- 有被 DDoS 的经历：再考虑高防。RakSmart 这类商家的高防机型单机可以做到 1Tbps 防御，但普通机型的默认防御普遍在 10G-20G 这个量级，对绝大多数网站已经够用。

- 跑 AI、推理：直接看 GPU 服务器，云集群从 GTX 1650 到 RTX A6000 独享不共享，¥229/月起。

还有一个下单前的小技巧：让商家把回程的 AS 号写清楚。电信 CN2 GIA 是 AS4809，联通精品网是 AS9929，移动 CMIN2 是 AS58807，联通普通骨干优化是 AS4837。肯写 AS 号的商家，线路一般确实有料；页面只喊“三网极速”却不给具体路由的，多留个心眼。

## 下单前，把这几件事在条款里翻一遍

机器出问题时能不能少亏钱，取决于下单前有没有看清退款、带宽、IP 和内容红线这几项。

1. **退款条款**。以 HopeIDC 公开的政策为例：流量用超 10G 不退、IP 被 GFW 或地区封锁不退、促销和优惠码订单不退。这三条在行业里非常普遍，所以“买年付再退款试机”这条路基本走不通；想先体验，优先找云集群这种明码标价给 24 小时免费试机的，或者干脆月付。
2. **带宽独享还是共享**。页面上那个大数字先当共享看。业务真吃带宽，下单前直接问客服哪一档是保证带宽，最好留个书面记录。
3. **IP 归属地**。机房 IP 多为广播 IP，查归属地可能显示别的地区甚至别的国家，能不能访问特定网站取决于对方用什么 IP 库。另外 IP 被墙一般不退，买之前心态上要接受这个风险。
4. **内容红线**。色情、赌博、欺诈、跨境访问节点这类内容，在几乎所有商家的条款里都是直接停机不退款，别拿正经租的服务器去试。

## 几个高频问题

### 美国服务器需要备案吗？

不需要。ICP 备案只管接入中国大陆机房的网站，美国机房不涉及，机器开通、解析指过去就能用。

### 洛杉矶服务器的延迟多少算正常？

三网直连线路约 130-160ms；普通国际线路普遍 200ms 上下。晚高峰丢包明显，说明线路绕路或拥堵，和硬件配置没关系。

### 外贸建站选美国还是香港？

客户在欧美，选美国，再配 CDN；客户集中在国内和东南亚，香港、日本机房的延迟体验更好。两边都有的，美国服务器加 CDN 是更省事的组合。

### “1Gbps 不限流量”能全信吗？

$50 就能买到 1G 不限流量的机器，几乎可以肯定带宽是共享的。介意的话下单前问清楚，或者看条款里有没有“保证带宽”的字样。

### 第一次买，月付还是年付？

月付。多数商家年付有折扣，但跑稳之前你不知道晚高峰的真实表现，而退款条款大概率帮不上忙。月付多花的那点钱，买的是一个随时止损的选项。
